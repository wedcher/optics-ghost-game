- `Mirror3.png`：同一輪的另一次嘗試，仍是有下框的掛鏡、鏡中畫死了反射。未使用。
- `Mirror1.png`、`Mirror2.png`：第一版用的背景（下面這段是當時的說明）。使用者試玩後認為太難玩，已換掉。

### 第一版的平面鏡房間背景（`Mirror1.png`、`Mirror2.png`，已不使用）

- 圖中的鏡子是**掛在牆上的有框鏡**，而且鏡子裡的反射是畫死在圖上的。定案是兩面互相垂直、由地板延伸到天花板的全高鏡，鏡中的像要由程式依幾何畫出來（見下方「平面鏡四格圖」與 `PROJECT.md`）。
- 2026-11-17 實作：只用圖裡的牆、鏡框、燈、窗、天花板；**地板與兩面鏡的鏡面由程式依幾何重畫**，鏡面畫到地板（蓋掉圖裡的下框）。相機參數對著 `Mirror1.png` 量，寫在 `prototype/plane-mirror/configs.js`；換圖要重量。細節與這張圖在玩法上的限制見 `docs/prototype-findings-mirror.md`。
- 若重畫：落地鏡（沒有下框）、玩家離正面牆近一點、鏡面留空（純暗色）、兩張圖除了碎鏡以外完全相同。
- 所以這兩張可以當房間的氣氛與底圖，但**鏡面範圍內的內容要由程式蓋掉重畫**，不能把圖裡畫好的反射當成答案；鏡子是否維持有框、是否全高，要先問使用者。

### 凹透鏡荒野背景

- 四張都是寬幅（約 3:1），**四個方位各用一張**，水平置中顯示。橫向手機一次看到約三分之二寬。
- 方位對應與各圖的地平線比例寫在 `prototype/concave-lens/app.js` 的 `BG_DIRS`。
- 圖中**沒有鬼、沒有地板格**，符合「探索時不顯示格子」。
- 凹透鏡內的畫面必須由同一張背景經光學重映射產生，**不能另貼一張縮小版圖、也不能只縮小鬼**。
- 凹透鏡 prototype 實際載入的是壓縮後的 `prototype/concave-lens/assets/wilderness-*.jpg`；換圖時兩邊都要更新。
- 色調尚未定案（見 `visual-handoff.md` §1），這幾張只代表目前喜歡的方向。

### 平面鏡四格圖

- 可參考的是**氣氛**（暗色木質房間、壁燈、金色法陣、封印成功的演出）與流程。
- 物理／規格上已知與定案**不符**的地方，實作時不要照抄：
  - 定案是**兩面互相垂直、由地板延伸到天花板的全高鏡**；圖中是牆上掛著的有框鏡，比較像螢幕。
  - 鏡中的地板格要和房間的格子在幾何上連續，像空間延伸到鏡後；圖中鏡內沒有地板。
  - 格 ③ 是「對鏡中像丟符」的錯誤示範；定案的攻擊方式是**選地板格展開封印法陣**。

### 凸透鏡走廊與鏡片

- 走廊圖是 2172×724 的側視圖。原型把圖中的**牆腳線**（約圖高 79.5%）對齊地板、**橫樑下緣**（約圖高 9%）對齊天花板，換算後整張圖約 1276×425 cm；走廊長 1000 cm 只用到中間一段。這兩個比例寫在 `prototype/convex-lens/app.js` 的 `ART.corridor`，換圖時要一起調。
- 鏡片圖去掉透明邊後縮到高 900 px，畫成口徑 240 cm 高。
- 原型實際載入的是 `prototype/convex-lens/assets/corridor.jpg` 與 `lens.png`。
- 火把是背景的一部分，位置固定，與鬼無關。
- **布幕還沒有圖**：目前是程式畫的 placeholder。需要的是「正面看」的一塊布幕（接近正方形、中央留空、素面、偏暗的環境光），側面在走廊裡只是一條細線，不需要另外出圖。

## 鬼：`ghost01.png`（第一關已換上；凸、凹透鏡原型尚未換上）

> 2026-11-17：使用者放入 `ghost01.png`。1060×1484（5:7）、透明背景；長髮白衣、右手高舉、左手持短刀，上下左右都不對稱，符合下面的規格。
> 整隻鬼都是半透明的（沒有完全不透明的像素），四周有一圈去背留下的淡色光暈，邊緣不平整、帶一點藍黃色邊；疊在暗色背景上看得出來。
> 換上原型後若覺得明顯，再請 GPT 重出一張邊緣乾淨的。以下是當初開給 GPT 的規格，留作重出圖時參考。

目前兩個原型的鬼都是程式畫的薄荷綠 placeholder。GPT 畫好後可以直接替換。需要的規格：

- **透明背景的 PNG**，單一隻鬼，正面、直立，四周留一點透明邊。
- 比例接近 **5:7（寬:高）**，例如 500×700。
- **上下、左右都要看得出差別**（例如頭在上、一隻手舉起、或手上拿東西）。凸透鏡的實像是上下顛倒且左右相反的，對稱的鬼看不出來。
- 整體偏亮、可以帶一點發光感：凹透鏡裡牠是夜晚荒野中的虛像，凸透鏡裡牠是投在暗色布幕上的光。
- 不要畫地面、影子或背景；不要把鬼畫成半身被裁掉。
- 風格和荒野、走廊的背景一致即可；造型不限。

替換時程式要做的事（給接手的 AI）：兩個原型的 `drawGhostShape`／`ghostPath` 改成畫圖片；凸透鏡的模糊是把同一張圖畫很多次疊加，圖片可以照用。目前測試用「畫面上有沒有鬼體色的像素」判斷鬼是否出現，換成圖片後要改用 `stats.ghostInLens`／`stats.ghostRevealed` 這類狀態旗標，或另外定一個判斷方式。
