# Physics Check — Concave Lens Reverse Construction

日期：2026-11-16

## 結論

Sprint 01 任務單中的凹透鏡反推作圖在薄透鏡近軸模型下是**幾何一致且可逆的**。

這裡留下計算痕跡，供後續 AI 與實作者核對，避免重複懷疑已驗證結論。

---

## 座標定義

- 薄凹透鏡位於 x = 0
- 主光軸為 y = 0
- 物體位於左側：O = (-d_o, h)
- 凹透鏡焦距 f < 0
- 物側焦點：F = (-|f|, 0)
- 真實物經凹透鏡形成左側虛像 I = (d_i, m h)，其中 d_i < 0

採常見薄透鏡關係：

1/f = 1/d_o + 1/d_i

因此：

d_i = f d_o / (d_o - f)

因 f < 0，所以 d_i < 0。

放大率：

m = -d_i / d_o

對凹透鏡的真實物：
- 0 < m < 1
- 虛像正立
- 虛像縮小
- 虛像位於透鏡與物側焦點之間

---

## 反推主光線 A：光心線

薄透鏡近軸模型中，通過光心的光線近似不偏折。

因此：

O、I、光心 (0,0) 共線。

由虛像點 I 經光心延長到物側，可得到物體所在方向。

---

## 反推主光線 B：焦點／平行線

正向規則：

- 由物點 O 發出一條平行主光軸的光。
- 它打到透鏡上的點 P = (0,h)。
- 經凹透鏡後向外發散。
- 發散光的反向延長線通過物側焦點 F。

因此反推時：

1. 從虛像 I 畫向物側焦點 F。
2. 延長此線直到透鏡平面 x = 0，得到 P。
3. 從 P 向物側畫一條平行主光軸的線。
4. 此水平線與「I → 光心」延長線相交的位置就是 O。

---

## 三組數值驗證

固定：
- |f| = 200
- 物體高度 h = 120

### Case 1

d_o = 300

計算：
- d_i = -120
- m = 0.4
- I = (-120, 48)

由 I-F 線延伸到 x=0：
- P = (0,120)

P 的水平線與 I-光心線相交：
- O = (-300,120)

與原物點完全一致。

### Case 2

d_o = 500

計算：
- d_i ≈ -142.857
- m ≈ 0.285714
- I ≈ (-142.857, 34.286)

反推：
- P = (0,120)
- 交點 O = (-500,120)

與原物點一致。

### Case 3

d_o = 700

計算：
- d_i ≈ -155.556
- m ≈ 0.222222
- I ≈ (-155.556, 26.667)

反推：
- P ≈ (0,120)
- 交點 O ≈ (-700,120)

浮點誤差範圍內與原物點一致。

## 對 prototype 的重要提醒

### VERIFIED
- 「虛像 → 光心」可作為第一條反推線。
- 「虛像 → 物側焦點 → 透鏡交點 P → 物側平行主軸」可作為第二條反推線。
- 兩條線可唯一恢復原物點。

### 仍需 UX 驗證
物理正確不代表學生看得懂。

Sprint 01 必須實測：
- 學生是否理解為何從虛像點連到焦點。
- 虛線延長與實際光線是否需要不同視覺樣式。
- 從探索視角切 90° 側視後，虛像標記是否仍能被認成「剛才看到的位置」。
- 手機上兩條線的操作是否直覺。

### 格子配置
建議 prototype 不隨機產生任意物距後才硬套格子。

較安全的方式是：
1. 先定義合法目標格中心。
2. 將物點放在格中心。
3. 再由物點與焦距正向計算虛像。
4. 玩家反推後自然回到該格中心。

如此可避免理論答案落在格線附近。
