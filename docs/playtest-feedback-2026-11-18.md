# 使用者試玩回饋（2026-11-18）

使用者玩過一輪之後的回饋，由 Claude 整理分類。**每一條都有編號**，分頁接手時用編號認領。標「❓」的還在等使用者回答，回答前不要動手做。

分類：
- **A 劇情演出**：台詞、字幕提示、音效、震動。
- **B 介面操作**：按鈕、選單、全螢幕、橫向。
- **C 玩法規則**：出鬼位置、清晰判定、標記、封印。這一類會影響物理正確性和答案。
- **D 畫面**：背景圖、鏡框。

> **分頁怎麼分**：建議**照檔案（關卡）分**，不要照 A～D 分。照類別分的話，A 和 B 都要改 `plane-mirror/app.js`，會撞檔案。最下面有建議的分頁表。

## 待使用者回答

- **Q1（G3 橫向）**：拿掉轉向提示後，手機直拿時畫面要怎麼顯示？網頁不能強制手機轉向（iOS 完全不行）。可行的做法：**偵測到直拿時，把整個遊戲旋轉 90° 顯示**，這樣鎖定直向躺著玩也是橫的畫面。觸控座標要跟著轉換，三關都要測。是這個意思嗎？
- **Q2（G4 選單）**：
  - 第一次開只有「開始遊戲」；過關後，原本「開始遊戲」那一項是變成「第一關：充滿鏡子的房間」嗎？
  - 第一關、第二關的「練習模式」：會扣命嗎？要計時嗎？（第三關的練習模式已經定案：不限時、不計排行、一樣扣命。）
  - 「重新開始遊戲」和「排行榜」入口照舊保留嗎？
- **Q3（G5 換關）**：目前每一關都是獨立網頁，瀏覽器換頁就一定會離開全螢幕，這點沒辦法繞過。要維持全螢幕，得把三關改成同一個網頁裡切換，是比較大的改動。可以接受「換關後點一下畫面就回到全螢幕」，還是一定要不中斷？
- **Q4（M1）**：「有一天……」放在第一句、古堡外觀圖之前或同時出現，對嗎？要不要寫進 Google 劇本？
- **Q5（M5）**：「鬼抓鏡子」是一句新的旁白（例如「女鬼抓住了右邊的鏡子」）嗎？還是指鬼抓鏡子的動畫？
- **Q6（M8）**：「右1、上1」是怎麼數的？是從玩家這邊看地板，靠右牆的第 1 排、離玩家最近的第 1 格嗎？截圖上標出格子會比較準。另外，那三格是不是真的兩面鏡子都照得到，要用目前的背景圖驗算過才算數。
- **Q7（V3 超清楚）**：照物理，實像只在**布幕剛好在成像位置**時才清楚；鬼如果剛好在**焦點**上，根本不會成像（光線平行射出）。猜你的意思是下面這樣，請確認：
  - (a) 放寬「清楚」的範圍，讓布幕在成像位置附近時都看得到清楚的像；
  - (b) **剛好對到成像位置**（最清楚）時，像外面描一圈線，寫「超清楚！」。
  - 「焦點」這裡指的是「對焦點（最清楚的位置）」，不是透鏡的焦點，對嗎？
- **Q8（C1）**：凹透鏡原本按「舉起凹透鏡」才看得到透鏡裡的像。改成「放下凹透鏡」是說**一開始就舉著**，按了才放下嗎？還是按鈕在舉起後才改名成「放下」？
